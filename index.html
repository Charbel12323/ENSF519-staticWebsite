Boardly

A simple Jira-style Kanban board built for university group projects. Create a group, invite your teammates, and keep every task in one place.

Created by Charbel Maroun and Aly Masani

About the project

Boardly lets users sign up, create a group, and manage tasks on a shared Kanban board. Tasks move between To Do, In Progress and Done, and the board, calendar, timeline and dashboard all read from the same task records, so everyone sees the same progress.

Features

  • AccountsEmail and password sign in with JWT auth.
  • GroupsCreate a group and invite teammates by email.
  • Kanban boardDrag and drop tasks and assign them to members.
  • DashboardCompletion, overdue tasks, workload and deadlines at a glance.
  • CalendarSee tasks by due date and drag to reschedule.
  • TimelineGantt view with milestones and task dependencies.
