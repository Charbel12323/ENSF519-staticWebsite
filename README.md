# Group 38 - Boardly

A static website for Group 38 and our project, Boardly.
It is plain HTML and CSS with no build step and no JavaScript.

## Files

- `index.html` - the page
- `styles.css` - styles, including dark mode and mobile layout

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.
